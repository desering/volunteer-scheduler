# How to use trainings, badges, regulars and messages

For admins. Everything below is in the admin panel under **Volunteers**,
except the insights, which have their own link in the sidebar. Background:
[Volunteer engagement](../explanation/volunteer-engagement.md).

## Set the rules once

1. Open **Volunteers → Volunteer settings**.
2. **Regular volunteers**: how many shifts in how many days make someone a
   regular, what regulars get (shown on their card), and a note for the card.
3. **Shift badges**: the milestones (e.g. 10 shifts 🌳).
4. **After a shift**: write the thank-you email and tick *Send a thank-you
   email after each shift* when you are happy with it. It is off until you do.

To give someone the perks regardless of shifts (staff, coordinators), open
the user and set **Regular volunteer** to *Always*.

## Run a training

1. **Volunteers → Skills → Create new**: a title, an emoji badge, a
   description of what people learn. Optionally: skills they need first, and
   after how many shifts we invite people.
2. Create the training event as usual (or from a template) and pick the skill
   under **Skills taught**.
3. Everyone who attends gets the badge automatically a few hours after it
   ends. If someone did not come, open the event → **Attendance** → *No-show*.

Taught someone a skill during a normal shift? Event → **Attendance** → pick
the skill next to their name → *Add*.

## Mark a no-show

Event → **Attendance** → *No-show*. You only need to do this for people who
did not come; everyone else counts as attended once the shift is over. Do it
within a few hours of the end if you can (see *Hours to wait* in the
settings): the thank-you email and badges go out after that.

## Email a group of volunteers

1. **Volunteers → Messages → Create new**: subject and text. `{name}` becomes
   each person's name.
2. Fill in only the filters you need under **Audience**, e.g. *At least 3
   shifts* and *Has none of these skills: Kitchen basics*.
3. **Save**. The box *Who will get this* lists exactly who receives it.
4. Press **Send to … volunteers**, then confirm. It goes out within a few
   minutes; each email sent appears under **Deliveries**.

Want to invite the same people on WhatsApp? Use **Download list** in the same
box for a spreadsheet with phone numbers.

A sent message can no longer be edited. Duplicate it to send something
similar.

## See how volunteering is going

Sidebar → **Volunteer insights**: who is active, who comes back after their
first shift, the busiest days, and people who used to come often but have not
for a month. **Download all volunteers** gives the same numbers per person as
a spreadsheet.
